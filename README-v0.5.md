# TREN v0.5 — in-app updates

One-time bootstrap: stop TREN; extract this ZIP; double-click upgrade.bat. It detects a standard Desktop/Tren-Local installation when exactly one exists, otherwise opens a folder picker (terminal fallback if Tk is absent). Start your existing start.bat and refresh TREN. No dependencies or model installs.

Thereafter: Settings → Updates → select a downloaded TREN release ZIP → Prepare selected ZIP → Install & restart. No extraction, path entry or external update script for future manifest-format releases. The app backs up code and snapshots SQLite, preserves current data/config/projects, waits for shutdown, installs with checksums, launches TREN in a detached process and checks startup. Startup failure attempts old-code rollback and relaunch. Pairing sessions still reset after restart in this milestone. Restart logs are private in data/updates/restart.log (can contain pairing output).

GitHub: enter a PUBLIC release repository as owner/repository; Check for updates → Download update → Install & restart. Requires a published stable release with asset TREN-vX.Y.Z.zip and GitHub SHA-256 digest. A TREN repository/release has not been created or published by this build; configure it after setup. Private-repository/token support is not included. ZIP import works without GitHub. Packages older than v0.5 lack the manifest and are rejected; use built-in Restore previous update for a prior in-app backup, or the printed bootstrap rollback command for the first update.

Checksums identify corruption; the selected repository/ZIP is the source of executable code and must be trusted. No cryptographic publisher signature is added. Limits: 16 MiB ZIP, 64 MiB expanded, 300 archive entries; restricted file/path allowlist. Updated modules outside the supported allowlist require an updater release first. No data/hosts/auth/model copying. Active/queued coding and scheduled jobs prevent install; finish/cancel them first. Installing is explicit, never automatic. Keep PC awake. If restart fails, open start.bat; result appears in Settings.

This release installs the updater only. GPT conversation layer, persistent pairing, desktop/iPhone app experience and voice remain future milestones in that order. Local v0.4 reliability tests were user-confirmed; v0.5 real Windows restart/update/rollback still needs local verification.
