PC agent

Ask VEYRA to inspect your PC, work with files, run installed commands or open apps. Read-only checks run automatically. File changes, launches and PowerShell scripts show an action to review before execution.

Broad access uses your Windows account across local drives. An administrator action also opens Windows UAC on your PC; VEYRA does not elevate its web server. Retrieved file and command evidence goes to GPT. General visual browser/desktop automation is not included yet. Opening an app may bring it to the foreground. Review scripts carefully: their effects are not automatically backed up.
